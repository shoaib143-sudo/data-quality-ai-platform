# Performance and Scalability Test Plan

## Workload dimensions

Measure small, normal, large, spike, stress, and endurance behavior across file size, rows, columns, findings, concurrent runs, concurrent users, agent/tool calls, storage throughput, and database load.

## Metrics

Latency percentiles, throughput, error rate, CPU, memory, database utilization, connection/queue depth, storage throughput, model latency/cost where applicable, timeout behavior, and recovery time.

## Rule

Operating envelopes and SLOs must come from product requirements. Until explicit limits are approved, tests characterize capacity but must not invent certification thresholds.
