# Accessibility and Browser Automation

## Accessibility

Run automated accessibility checks on critical pages and journeys, including keyboard/focus behavior where automation can reliably assert it, semantic names/roles, form errors, contrast tooling, and dynamic-state announcements.

## Browser matrix

Execute critical browser journeys on every officially supported browser engine and viewport class. The support matrix must be explicit. Unsupported environments are not silently counted as certified.

All checks remain unattended; no manual accessibility or browser step is a certification dependency.
