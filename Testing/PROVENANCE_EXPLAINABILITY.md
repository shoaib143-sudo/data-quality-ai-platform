# Provenance and Explanation Fidelity

## Provenance chain

For consequential outcomes verify:

```text
source
-> version/transformation
-> metric/evidence
-> finding/classification
-> policy/control
-> AI recommendation/plan
-> approval
-> execution
-> post-state
-> audit/certification evidence
```

Every link must reference the correct scoped object/version.

## Explanation fidelity

Explanations must be supported by the actual evidence and executed trajectory. Automated checks should detect fabricated citations, nonexistent tools/actions, unsupported causal claims, and explanations inconsistent with stored execution evidence.
