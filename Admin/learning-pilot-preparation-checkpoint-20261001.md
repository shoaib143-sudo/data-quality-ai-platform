## Important correction to the next-step plan

The budget module was implemented and deployed, but configuring provider quotes and a policy does not complete end-to-end self-improvement. The independent review found no production caller joining the candidate, held-out cases, paired ledger, evaluator, decision and scoped budget invocation. Aggregate evaluation RPCs still rely on trusted service-supplied claims rather than deriving all claims from joined canonical case and settlement evidence.

The next implementation module must build a server-owned paired experiment runner and evidence collector. Its scope is:

1. Load and integrity-bind actual baseline/candidate artifacts and replayable held-out inputs.
2. Resolve current project/agent/skill/mode authority, independent evaluation identity and predeclared policy.
3. Persist durable case/arm/run/attempt identities before dispatch. Supply the existing scoped budget guard and verified quote port. Re-entry must not repeat an ambiguous paid attempt.
4. Bind actual input/output artifact hashes, versions, invocation and canonical cost settlements to each arm and terminal outcome.
5. Score persisted outputs independently and derive the aggregate decision from complete canonical evidence, including failure denominators and the locked analysis plan.
6. Keep $0 synthetic traces segregated from non-synthetic ledger rows. Validate the joined workflow in a disposable fixture before proposing live activation.
7. Preserve approval, controlled release, canary, rollback and the existing Vercel/Cloudflare parity hold.

Read-only environment metadata access, verified source replay, actual reviewer independence and any positive spending approval remain distinct from implementable native runner work. Missing configuration must not be replaced by fabricated approvals, prices or zero-cost claims about an unverified backend.

No ADR-007 agent classification changed. DataNexus keeps authentication, project scope, evidence, budgets and release authority; external evaluation/durable-execution patterns remain replaceable design references.
